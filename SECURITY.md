# Security and disclosure

Do not upload confidential tables, calibration targets, public-release ledger
files, raw-dependent evaluation, access tokens or credentials to issues or pull
requests. Use a minimal synthetic reproducer.

RUPA is research software. Its conditional mathematical model and automated
checks are not an independent implementation-security or compliance assessment.
The local interface and research paths must not be used to bypass the supported
production CLI authorization and cumulative accounting.

Private vulnerability reporting is enabled for this repository. Use
https://github.com/ghygood111-cloud/rupa-privacy/security/advisories/new for
sensitive reports. Do not post a working sensitive exploit, confidential data or
personal information in public Issues. No private contact email is invented.
