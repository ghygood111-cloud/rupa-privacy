本地科研数据隐私发布软件 · 复现模式

第一次使用

  1. 先解压整个压缩包。保留 RUPA.exe 与 _internal 在同一文件夹。
  2. 双击 RUPA.exe，稍等默认浏览器自动打开。
  3. 点击 Load official synthetic example，加载内置合成示例。
  4. 左侧 Validation → Run validation，确认通过。
  5. 左侧 Run → Run RUPA，等待运行完成。
  6. Analysis 查看 Risk、Utility、Epsilon Allocation、Released Data、Constraint Residuals。
  7. Export 下载最终发布 CSV 或完整公开运行包。

首页也可加载 Hazardous-waste synthetic example，查看企业年度危废合成数据的 18 个拟发布字段及被排除的企业标识、地址和联系信息。该案例不包含信息中心真实记录，不能用于正式联单业务。

软件做什么

软件在公开固定主体名单的数据契约下，读取独立校准集与待发布数据，按配置确定字段风险、效用和预算，执行数值/类别扰动及公开线性约束后处理，最后生成可核查的公开发布产物。

release_data.csv 才是最终发布数据。校准数据不是发布结果；风险分数不是攻击成功率；效用权重不是实测准确率；约束残差下降不代表最终数据严格满足所有物理关系。

此 Windows 版仅用于公开或合成数据的科研复现演示。不要输入真实保密数据，不提供 production 发布入口，不构成监管合规或独立隐私认证。作者与开源授权仍待确认。

结果和日志

结果保存到当前用户 %LOCALAPPDATA%\RUPA\runs；启动日志为 %LOCALAPPDATA%\RUPA\logs\startup.log。无需操作 _internal。

Notes

本地工作流程无需联网。RUPA 只在当前电脑的 localhost 上运行，本评估版仅使用复现模式。请勿重命名或删除 _internal。

无法打开时

端口被占用时软件自动选择其他可用端口。启动失败会显示日志位置。不要删除依赖目录，不要从压缩包内直接运行 EXE。

关闭浏览器并不结束后台服务。使用结束后可在 Windows 任务管理器中结束 RUPA.exe。软件未签名；不要绕过系统安全警告，必要时请学校 IT 核验来源和文件 SHA-256。
