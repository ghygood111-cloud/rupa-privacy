RUPA 科研软件试用说明

双视图研究更新版，2026年10月22日。请先完整解压整个压缩包，再双击 RUPA.exe。不要只取出 EXE，旁边的 _internal 文件夹必须保留。

软件在本机启动服务并打开浏览器，仅监听 127.0.0.1。程序会选择可用端口，实际地址以启动时打开的页面为准。网页不是远程网站，不需要注册或登录。关闭标签页不会自动停止后台程序。

体验原参考流程

  1. 首页点击 Load official synthetic example，也可以选择危废或水处理合成示例。
  2. 左侧 04 Validation → Run validation。成功后自动进入 Run。
  3. 点击 Run RUPA。成功后自动进入 Analysis。
  4. 查看预算、受保护数据及约束残差，点击底部 Continue to Export 下载参考流程的结果。

体验新双视图研究方法

  1. 先在首页加载一个合成案例，再点击左侧 08 Research。
  2. 选择 Task-directed + risk cap，点击 Run two-view research。它会实际验证输入并运行新方法。
  3. 页面显示总预算如何分为逐行、总量和类别三部分，三部分之和仍为总 epsilon。
  4. 查看本页的 Research result、分字段预算和重建前后残差；本模式结果不放在原流程的 Analysis 页。
  5. 点击 Download research CSV 下载最终表，或 Download research package 下载带清单的研究结果包。
  6. 选择 Uniform comparator 并重新运行，可体验相同双视图方法内的均匀总量预算方案；它不是原逐行流程。

Downloaded files are saved by your web browser according to its normal download settings, typically in the Windows Downloads folder. 软件不会猜测或强制设置浏览器下载目录。

如何理解结果

该方法用受保护总量引导行表重建，以缓解旧逐行流程的总量偏差。准确总量不等于恢复每条原始记录；方差、相关性和部分误差指标仍可能变差。单次演示也不能证明某种预算总是优于另一种预算。论文中的多样本、配对种子实验与本机单次演示分开报告。

本版为科研评估界面，不是保密生产发布工具。双视图模式拒绝生产、保密发布及秘密校准输入，不替代 CLI 隐私账本，不提供合规或独立安全认证。自带案例均为合成数据。原参考流程保持可用。

排错与限制

启动日志位于 %LOCALAPPDATA%\RUPA\logs\startup.log；实际地址记录在 last_startup.json。结果保存在 %LOCALAPPDATA%\RUPA\runs。程序未数字签名；如安全软件提示，请先核验来源和 SHA-256 并由本机管理人员判断，不要关闭系统安全保护。本机已执行启动、计算和导出核验，但尚未在无 Python 的独立干净电脑或 Sandbox 中验证。
