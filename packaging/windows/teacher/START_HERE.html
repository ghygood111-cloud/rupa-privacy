RUPA Evaluation Build

Welcome to the RUPA evaluation build.

To start

  1. Extract the complete ZIP archive.
  2. Double-click RUPA-Evaluation.exe.
  3. Wait for the browser to open.
  4. Click Load Official Example.
  5. Run Validation.
  6. After validation passes, RUPA will automatically continue to the Run page.
  7. Run RUPA.
  8. After completion, RUPA will automatically open Analysis.
  9. Review the analysis results.
  10. Click Continue to Export.

Important

  • Do not delete or rename the _internal folder.
  • No Python installation is required.
  • The program runs locally on your computer.
  • Internet access is not required for the normal evaluation workflow.
  • Downloaded files are saved according to your browser's normal download settings.
If anything is confusing or you are unsure what to do next, please record the issue rather than trying to troubleshoot it yourself.
