RUPA 是什么？

RUPA 是工业表格数据的隐私发布科研软件。在固定公开主体名单、每个主体一行的数据设定下，它利用独立校准数据估计字段风险和效用，分配隐私预算，对数值和类别字段进行扰动，并通过公开线性等式约束降低残差，生成可核查的最终公开数据。

本测试版用来评估：第一次使用是否看得懂、操作是否顺畅、图表和结果解释是否清楚。它不是正式发行版，不是生产发布工具，也不保证最终数据严格满足所有物理关系。

如何启动

先解压整个测试包；RUPA-debug.exe 和 _internal/ 必须在同一文件夹。不要从压缩包内直接运行，也不要只发送一个 EXE。

只使用内置示例或获准公开的演示数据，不要输入真实保密数据。Debug 版运行时保留一个控制台窗口是正常现象；测试期间不要关闭它。软件尚未签名，如遇系统安全拦截，请交由 IT 核验，不要绕过安全警告。

完成一次官方示例：11 个操作

  1. 双击 RUPA-debug.exe。
  2. 等待浏览器自动打开。若没有打开，查看控制台显示的本机地址；端口不一定是 8501。
  3. 在首页点击 Load official synthetic example（即评审任务中的 Load Official Example）。Data 和 Configuration 变成 Ready 表示已加载；当前不会自动跳转。
  4. 点击左侧 04 Validation。若导航折叠，先点击左上角展开箭头。
  5. 点击 Run validation，确认出现 VALIDATION PASSED。
  6. 点击左侧 05 Run。
  7. 点击 Run RUPA，等待 Run completed successfully。
  8. 点击左侧 06 Analysis。
  9. 依次查看 Overview、Risk、Utility、Epsilon Allocation、Released Data、Constraint Residuals、Audit。
  10. 点击左侧 07 Export。
  11. 点击已有下载按钮。Analysis 中还提供 released CSV 和 residual plot data 下载。请记录是否触发下载以及文件名，不必寻找固定保存位置。

Downloaded files are saved by your web browser according to its normal download settings, typically in the Windows Downloads folder.

读懂输入和结果

页面中的词含义
Calibration dataset用于估计风险和效用等参数的独立校准数据，不是最终发布结果。
Release dataset等待隐私处理的输入表，不是输出文件。
Configuration事先指定字段、公开边界、公开类别域、预算和线性约束的设置。默认案例不需要修改。
Risk / NMI校准数据上的关联诊断，不是攻击成功率，也不是正式 DP 隐私保证。
Utility weight预算分配的效用优先权重，不是预测准确率或已测得的数据效用。
Epsilon隐私预算；更大通常允许更小的扰动，但隐私界限更弱。
Constraint Residuals四阶段残差及 violation rate。残差下降不等于所有记录最终严格可行。
release_data.csv当前运行生成的最终公开发布表，不包含敏感目标值或原始私有输入表。

Supported public equality residuals are reduced, but exact final feasibility is not guaranteed. 官方示例的最终 violation rate 可能仍为 1；请如实检查，不要仅根据残差下降判断严格一致。

如何给出评审意见

按 REVIEW_TASKS.md 完成任务，在 REVIEW_FEEDBACK.md 填写评分。文件可用任意文本阅读器打开；若浏览器提示下载，保存后打开即可。

reviewer_evidence/ 中的证据由开发者在当前电脑实际运行生成，不是您的独立评分。您自己的运行会有新的 run_id，请将新截图和导出文件另行保留，勿覆盖这套参考证据。

关闭浏览器不会结束程序。完成后关闭 Debug 控制台即可结束该进程。若启动失败，查看提示的启动日志位置；无法解决时记录错误交给开发者，不需要安装开发工具。
