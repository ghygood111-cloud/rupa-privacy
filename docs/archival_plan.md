# Optional version archival

No Zenodo deposit or DOI exists for this software version yet. Do not assign an invented
DOI, reserve an identifier in the manuscript without a real record, or present a
local archive as permanent public hosting.

After the owner approves the file manifest and the actual GitHub release exists:

1. Use the owner's normal Zenodo/GitHub authorization, not a token shared in chat.
2. Archive the exact release tag and its software/source artifacts, checksums and
   reproduction report. Keep source version, author and license consistent.
3. Record third-party data licenses separately from BSD-3-Clause software code.
   Preserve Ontario OGL and UCI CC BY 4.0 attribution when those derivatives are
   included. The RUPA license does not relicense benchmark data.
4. Confirm a publicly accessible version-specific record and DOI from Zenodo.
5. Add only that actual DOI to CITATION.cff, README and the paper; keep version DOI
   and concept DOI distinct if both are issued.

Publication, archival and independent reproduction are separate evidence. The
current task's local tests do not establish all three.
