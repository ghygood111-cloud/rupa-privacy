# Changelog

All notable changes to the RUPA research software are recorded here.

## [Unreleased]

## [0.1.1] - 2026-10-23

### Fixed

- GUI reproduction-command recipes remove Windows, UNC and POSIX directory
  prefixes identically on every host, including the displayed run ID.
- Added cross-platform path-redaction regression cases. The v0.1.0 hosted Linux
  test failure remains part of its unchanged historical release record.

### Provenance

- Only GUI command presentation, regression tests and version/release metadata
  changed. No scientific computation or privacy accounting changed.
- The paper's v0.1.0 core hash inventory is retained. A separately declared
  version.py-only metadata hash identifies this patch without relabeling it as
  byte-identical to v0.1.0. All other 38 core Python files remain identical.

## [0.1.0] - 2026-10-23

### Added

- Fixed-roster, mixed-type differential privacy release pipeline.
- Numerical Laplace mechanism and categorical generalized randomized response.
- Attribute-level risk/utility-aware epsilon allocation.
- Public linear-equality residual-reducing post-processing.
- Production privacy ledger, release manifests, and public/internal artifact separation.
- Reproducibility mode, command-line interface, examples, and local tutorial Demo.
- Portable CI contract and locked SoftwareX reproduction workflow.
- Optional uniform and bounded balanced numerical allocation; legacy default retained.
- Public/synthetic-only total-query and two-view reconstruction research interfaces.
- Four-path evaluation drivers, metrics and attributed public benchmark fixtures.

### Fixed

- Removed the unsupported Studio execution path from the distributed package.
- Rejected non-finite privacy and accounting parameters at the trust boundary.
- Required normalized regulatory priors.
- Fixed deterministic NMI preprocessing and added effective-bin diagnostics.
- Rejected constant or degenerate calibration targets.
- Unified malformed YAML and configuration errors for CLI users.

### Distribution preparation on 2026-10-23

- Copyright holder confirmed as 高涵, affiliated with 中国矿业大学; BSD-3-Clause
  source license and structured citation metadata prepared.
- Full-validation dependency and CI declarations include the optional GUI and
  research tools used by the current tests.
- This candidate preserves the paper snapshot's 39 core Python files. It does
  not change NMI, utility, allocation mathematics, mechanisms, projection,
  accounting, production randomness or stored experiment outcomes.

The owner approved the 237-file clean public snapshot on 2026-10-23. The public
repository is https://github.com/ghygood111-cloud/rupa-privacy. No archival DOI
has been assigned.
The older local `v0.1.1-p0` tag is an internal historical baseline, not a previous
public release, and will not be uploaded as the paper's version.
